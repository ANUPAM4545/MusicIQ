# Contributing to MusicIQ

First off, thank you for considering contributing to MusicIQ! 

## Development Setup

1. Fork the repo and create your branch from `main`.
2. Run `docker-compose up --build -d` to spin up the local development environment (Frontend, Backend, PostgreSQL).
3. If you've added code that should be tested, add tests.
4. Ensure the test suite passes.
5. Format your code (Prettier for frontend, standard Java conventions for backend).

## Pull Request Process

1. Update the README.md with details of changes to the interface, this includes new environment variables, exposed ports, useful file locations and container parameters.
2. Ensure your PR follows the provided Pull Request Template.
3. You may merge the Pull Request in once you have the sign-off of two other developers.

## Reporting Bugs

Please use the provided Bug Report Issue Template. Ensure you include steps to reproduce, expected behavior, and environment details.
